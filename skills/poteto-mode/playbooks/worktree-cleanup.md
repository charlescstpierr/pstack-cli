### Worktree and simulator cleanup

**You own the disk and the safety gate.** Prune merged or abandoned git worktrees and stale iOS simulators to reclaim space. Deletion is irreversible, so every step guards against deleting something in use or holding uncommitted work.

**Tooling this playbook assumes.** pstack-cli bundles the read-only `scripts/worktree-audit.ts`; run `bun scripts/worktree-audit.ts [repo-path] [session-store-dir]` in step 1. It audits only and never removes a worktree. Disk commands below are macOS/Linux (`df -h /`, `du -sh`). On Windows use `Get-PSDrive C` and `Get-ChildItem | Measure-Object -Sum Length` equivalents, and skip step 6's simulator parts, which are macOS only.

1. Snapshot and audit. Record `df -h /` on Unix or `Get-PSDrive C` on Windows, then run `bun scripts/worktree-audit.ts [repo-path] [session-store-dir]` (**principle-build-the-lever**). It reads paths from `git worktree list --porcelain`, never hand-typed, and reports size, age, merge state, uncommitted work, remote and PR state, recent session activity, and a suggested bucket. The bundled audit is read-only. The transcript scan is slow, so send it to a delegate in a sibling pane (`pstack-cli delegate --task-id <id> --role "judgment and prose" ...`).
2. The bucket is advice, not permission. The user's active sessions are the real artifact (**principle-prove-it-works**). There's no sidebar here, so get the list of sessions and worktrees the user still cares about from the user directly, plus `pstack-cli tasks` for anything a delegate is currently in. Cross-check every candidate against that set. An audit has marked `safe` a worktree the user was still using, so the user's list wins.
3. Verify usage before deleting. For every `verify-recent-chat` row, or anything you doubt, fan delegates out to read the transcripts and report whether the session is ongoing and which worktrees it touches (**principle-guard-the-context-window**, transcripts are bulk). A live session spawns arena and repro trees into sibling worktrees through background delegates, and those are in use even when their names never come up in conversation.
4. Pause on irreversible loss. `wip:N` is N tracked uncommitted edits. Show the diff and get a decision first, since removing a clean worktree is recoverable from its branch but uncommitted work is gone. `scratch:N` is untracked throwaway, safe to drop, but name the files. Per Autonomy, clean and merged and not-in-use proceeds. `wip` and in-use pause.
5. Prune the confirmed set. Per path, `git worktree remove --force <path>`. If the dir survives on ignored build artifacts, `rm -rf` it, then `git worktree prune`. Branch refs survive, so no commits are lost. Confirm with `df -h /` and re-list with `git worktree list`.
6. Simulators and other reclaimers (macOS). Simulators are usually the next-biggest win. `xcrun simctl --set testing delete all` (XCTestDevices clones), `xcrun simctl delete unavailable`, and `xcrun simctl runtime list` then `runtime delete <id>` for old runtimes. More when needed: Xcode `DerivedData` and `iOS DeviceSupport`, your agent CLI's own state and snapshot directories when one balloons, package caches (pnpm, uv, brew, yarn). Clear only caches the user has not said to keep.

This is the one playbook that deletes user state with no code review to catch a slip, so the gates above are the review.

**Reply:** `df -h /` before and after with space reclaimed, the worktrees pruned, and a one-line reason for each held back (in-use by which session or worker, or uncommitted work).
